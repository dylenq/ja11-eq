    - Response points: `responsePoints(for:includePreGain:points:)` returns exactly `points` points, first x = 0, last x = width, x strictly increasing; for a flat curve every y equals y(0); for a +12 dB peak at 1000 Hz, Q 1 the lowest y (top) is within one pixel of y(12) near x(1000); a curve whose response exceeds +15 dB (several stacked boosts) has y clamped to 0 and none below 0; with `includePreGain` true and pre-gain -6 every y is larger than the no-pre-gain y by y(-6) - y(0) for a flat curve.
    - Clipping: a flat curve gives no ranges; a +6 dB peak at 1000 Hz with pre-gain 0 gives one range that contains x(1000); the same curve with pre-gain set to `autoPreGain()` gives none; with pre-gain -12 none; two separated +6 dB peaks (200 Hz and 5000 Hz) give two ranges in ascending order; ranges are within 0...width.
    - Degenerate size: a geometry with width 0 or height 0 returns 0 from every mapping, an empty array from `responsePoints` and `clippingRanges`, and never traps.
  </behavior>
